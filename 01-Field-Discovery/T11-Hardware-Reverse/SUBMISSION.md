## 四、证据链怎么验

照片若被替换，`manifest.csv` 里的 SHA-256 会对不上。在本目录下执行：

```bash
python -c "
import csv,hashlib
for r in csv.DictReader(open('photos/manifest.csv',encoding='utf-8')):
    h=hashlib.sha256(open('photos/'+r['filename'],'rb').read()).hexdigest()
    print(('OK ' if h==r['sha256'] else 'FAIL ')+r['filename'])
"
```

当前 6 张全部 `OK`。**本人现场同框照**是 `photos/00-on-site-with-teardown.jpg`，
面部已遮挡——遮挡只去掉身份信息，不影响「人—拆解件—工作台」在同一画面内的对应关系。

## 五、必须提前说明的四件事

1. **全文没有电气测量。** 拆解全程未通电，所有拓扑结论标注为【推】（目视推断），
   正文不出现「实测」「测得」。这是本报告的证据等级约定，不是疏漏。
2. **主控型号不认定。** U1 被二维码标签整片覆盖，四边为外伸海鸥翼引脚（LQFP 类），
   与同代 `STM32L100R8T6`（LQFP-64）封装相符**而非相悖**；但照片分辨率不足以数清引脚，
   LQFP-48/64/80/100 均不能排除，故不猜、不套用。
3. **接线验证未做。** 改造方案停在「可执行」而非「已验证」，
   因需先量 `FB1` 通断、`Z*` 钳位、3.3 V 轨对地阻抗，**确认电位前不得上电**。
4. **整机是否原厂无法判定。** 报告初版曾判为「跨代拼装件」，依据是主板日期码与传感器
   日期码相差 7 年；该推理把**裸板制造日期**当成**整机装配日期**，已撤回。
   详见 §0 ① 与 §0.1 勘误表（三处错误逐条列出，含错误原文）。

第 1、3 条是本次最实质的缺口，已在 §6.6 与 §7 第 1、5 条写明补齐方式（万用表三步，约 10 分钟）。

## 七、一句话结论

本机的技术价值不在于「它是不是一台原厂 G502」，而在于**用可见丝印能推到哪一步、
推不到的地方如何交代**：主控板与按键板同为 2015 年裸板、传感器板是 2022 年制造的 HERO 专用板、
外壳为第三方件、主键微动被换过——这些都能读出来，但合起来**不足以判定整机是否为原厂**。
裸板日期早于装配日期是常态，换壳换微动是二手件最常见的两种维修。
报告因此把结论停在「无法判定」，而不是拼一个更精彩但站不住的故事。
可交付的是这套能被人照着复核的证据链与【读】/【推】/【未】标注体系，
以及一处被本人当场问倒、随后查证并公开撤回的错误（§0.1）。
