## 与 `shots/` 的区别

`PowerProbe.zip` 里的 35 张 `shots/*.png` 是 App 通过 `screencap` 自动落盘的**设备屏幕截图**（1220×2712），用于证明工况确实在执行；本目录是**相机拍下的实物与环境同框照**，用于证明测试在真机、真实场景下完成。两者不能互相替代。
