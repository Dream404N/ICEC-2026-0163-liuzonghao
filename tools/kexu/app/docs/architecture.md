# 架构与数据契约

## 模块边界

`src/domain` 负责北京时间日期、周次解析、排课展开、冲突与提醒计划。`src/data` 负责 IndexedDB 状态、表格、备份和同步合并。`src/platform` 适配设备通知与文件分享。`src/ui` 提供共享页面。`electron`、`android` 提供原生入口。

唯一持久状态为 `AppState`，schemaVersion 为 1。每次编辑先更新内存，再按顺序写入 IndexedDB；保存失败在页面显式提示立即备份。存储初始化或结构校验失败时不覆盖原存储。

## 数据模型

| 类型 | 主要字段 | 约束 |
|---|---|---|
| Semester | 名称、第一周周一、总周数、作息、归档标记 | 1–60 周，周一日期可暂空，至少一个有效时段 |
| Course | 学期、名称、默认教师 / 教室、颜色、备注、提醒覆盖、静音、待校对 | 名称 / 教师 / 默认教室最多 200 字；待校对不生成提醒 |
| Rule | 课程、星期、起止时间、显式周次数组、教师 / 教室覆盖 | 星期 1–7，不能跨日，周次不重复且在学期内 |
| Adjustment | 课程 / 规则、原日期、新日期时间、类型、教室 / 教师、备注 | cancel / change / extra；同一原课程只允许一条非补课调整 |
| Entry | 类型、值或墓碑、服务端版本、本地脏标记、修改时间、远端冲突 | 每条记录独立比较版本，ID 不复用给其他类型 |

所有排课按 `Asia/Shanghai`（UTC+8）计算，不依赖设备当前时区。课程实例由规则 ID 与原日期标识；单次调课抑制原实例，生成新实例。跨大节使用一条完整时间规则，不按大节拆成多次提醒。

## 提醒接口

`planReminders(state, now, days)` 输出稳定键、整型系统 ID、标题、正文、提醒时刻和上课时刻。重复提前时间去重，哈希 ID 碰撞时顺移。计算所有未归档学期，跳过静音 / 待校对课程和已过去的提醒。

- Windows：renderer 只能调用 preload 暴露的五项 IPC，主进程校验发送窗口、数据条数与字段长度。`ReminderScheduler` 每 500ms 检查持久计划，串行写入 `popup-reminders.json`（临时文件重命名），以 key + at 去重。`PopupManager` 创建沙箱化无边框窗口，`focusable:false`、`skipTaskbar:true`、`showInactive()`；定位主屏工作区右下角，最多叠放 3 条，其余排队，随屏幕工作区变化重定位。专用 preload 只给该窗口内容 / 操作权限，字符串用 textContent 展示。12 秒自动收起、悬停暂停、5 分钟稍后提醒。源课程删除 / 改时取消旧卡片与相应稍后提醒。云端不保存弹窗计划。旧版 PowerShell helper 仅用于升级时清除本应用遗留的系统 Toast，正常提醒不再调用它。
- 安卓：LocalNotifications 插件保存系统 AlarmManager 计划，支持通知权限、精确闹钟权限检查和开机恢复。安卓 8+ 预建有声、静音两个渠道；旧版使用内置 WAV。渠道最终受系统设置控制。
- 浏览器：仅在页面运行时轮询，用于开发预览，界面说明后台限制。

提醒采用串行、合并更新，避免多个异步刷新把旧计划重新写回。配置覆盖后取消旧计划。安卓最多安排最近 450 条；Windows 最多接收 4000 条，超限报错。设备关闭提醒时取消当前所有计划。Windows 保留最近一天的来源键以免界面刷新误删稍后提醒，已发送状态阻止重复投递。Windows 需要托盘进程运行；彻底退出、关机或锁屏期间不能展示自绘卡片，休眠恢复只补发最近十分钟且未上课的提醒。

## 同步接口

服务端表 `schedule_records` 的主键为 `(user_id,id)`，仅认证用户可读取自身记录。禁止客户端直接 INSERT / UPDATE / DELETE，通过 `write_schedule_record(p_id,p_kind,p_payload,p_expected_revision)` 写入。

RPC 从 `auth.uid()` 取得账号；事务锁按账号与记录隔离。版本一致则写入、版本加一；版本不一致返回 `{ok:false,record}`。客户端不得提交 user_id 或自行指定服务端新版本。`payload=null` 保留删除墓碑。

客户端分页全量拉取（每页 500），避免时间游标边界漏记录；保留尚未上传的本地值与远端冲突。上传确认只清除本次送出版本的脏标记，期间的新编辑继续待上传。创建先父后子、删除先子后父，降低短暂引用不完整的影响。同步不是全课表单次事务，网络中断后下次继续。

`device` 偏好、账号归属、最近同步信息不上传。一个本地数据集绑定一个账号；换号需备份并清空。未配置服务时不构造云客户端，不上传任何课表或图片。

## 边界

不包含常驻 OCR、教务自动抓取、多人班级管理、考试模块或桌面小组件。截图为人工转录的初始数据，不调用在线识别。周课表在手机上横向滑动，今日列表适配窄屏。作息变更用于刻度与新规则默认值，不擅自改动已保存课程。
