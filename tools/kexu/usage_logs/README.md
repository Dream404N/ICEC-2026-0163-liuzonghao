# 课序客户端运行日志 · 目录口径

这个目录**不是人手写的过程记录**，也不是云端 Actions 的运行日志，
而是 Windows 客户端「课序 0.1.2」把本机真实使用事件通过 GitHub Git Data API 直接提交的产物。

- 文件名按北京时间日期分片：`YYYY-MM-DD.jsonl`，每行一条 JSON 事件。
- 提交者就是客户端自己，commit message 形如
  `课序运行日志 2026-11-15（真实事件 5 条，manual）`。
- 字段：`ts`（UTC）、`date` / `local`（北京时间）、`event`、`detail`、`ok`、
  `source: kexu-desktop`、`app`（版本）、`platform`。
- 只记真实发生的操作：启动、退出、提醒弹出、测试提醒、提醒计划变更、开机启动开关、
  休眠恢复、手动同步、同步失败/跳过。**不记课表内容、账号、凭据**；写入时脱敏，
  提交前还会机械拦截疑似密钥串。
- **没有日志的日子就是没有**：关机、断网、没打开应用都不补写、不造心跳、不生成空提交。
- 本仓库的同步脚本 `.workbuddy/sync_to_github.py` 把本目录列为保护目录：
  本地既不能删，也不能用旧快照覆盖远端日志，避免把客户端刚上传的真实证据抹掉。
  本文件是唯一的例外（纯说明文档，不是日志）。

## 与别的日志怎么区分

| 目录 | 谁产生 | 含义 |
| --- | --- | --- |
| `tools/kexu/usage_logs/` | 本机 Windows 客户端「课序」 | 客户端真实使用事件（本目录） |
| `tools/dingding/usage_logs/` | 本机「叮叮课表」EXE | 另一套本地客户端日志，互不冒充 |
| `02-20Days-Challenge/process_logs/` | GitHub Actions（`prebell-bot`） | 云端定时任务的运行/验真日志 |
| `02-20Days-Challenge/iterations/` | 本人手写 | 迭代说明与勘误 |
