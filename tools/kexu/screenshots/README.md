## 五、顺带发现的一项口径不一致（不是错误，但需说明）

三处对「提前多久提醒」的表述不同：

| 位置 | 值 |
|---|---|
| PreBell 云端（`timetable.json` 的 `remind_at`） | 课前 **20** 分钟 |
| 课序客户端（本截图「默认提前 30 分钟提醒」） | 课前 **30** 分钟 |
| 叮叮课表（`README.md`） | 默认 **20** 分钟，可调 0/5/10/15/20/30/45/60 |

**三者是三套独立产品，各自可调，不构成矛盾**，但并排看容易被误读为「同一个软件前后不一」。
若评审追问，应按「三套产品」回答，不要说成同一套的改动。

另：`tools/kexu/app/src/domain/seed.ts` 里源码默认值是 `leads: [15]`，
而本机实际运行值是 `[30]`。这是使用者在设置里改过，属正常行为，但在源码快照与运行态之间确实存在差异，
此处一并记录，避免被当成数据错误。
