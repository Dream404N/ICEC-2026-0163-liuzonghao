# 安全与隐私口径

## 数据来源

只访问 `src/sources.json` 里列出的**公开、匿名可访问**网页。不登录、不携带 Cookie、不提交表单、不调用任何需要身份的校内接口。

明确不碰：

- 微信本地数据库、聊天记录、群消息（相关开源项目已被批量下架，不做逆向）；
- 超星学习通、教务系统、校园网认证等需要账号或企业资质的接口；
- 任何同学的姓名、学号、手机号、照片、位置、设备信息。

## 日志脱敏

`src/chain.py` 统一处理，写入前机械抹除：Windows 用户路径、IPv4、完整 URL。时间只到日期 + 分钟，不记毫秒、UTC 偏移、主机名、绝对路径、请求正文。

报错只保留脱敏后的 8 位 SHA-256 指纹用于归类，不写原始堆栈。页面内容只存 8 位指纹与链接，不落全文到日志。

## 反馈采集

8 位同学只需回答「有没有漏提醒 / 有没有误报 / 提前多久合适」，以编号归档（F01–F08）。不收集可识别个人身份的字段，截图如有昵称需自行打码后再归档。

## 密钥

本模块不含任何密钥。GitHub Actions 使用仓库自带的 `GITHUB_TOKEN`，权限限定 `contents: write`。工作区外 `.workbuddy/.gh_token` 用于同步脚本，永不入库；`.gitignore` 与同步脚本的 `assert_no_secrets()` 双重拦截密钥串与敏感文件名。

## 诚信边界

- 缺勤轮次不补写，`verify.py` 会如实报出；
- 抓取失败、解析失败如实记录，不删不改；
- `preview.html` 是版式样张，内含示例数据且已醒目标注，**不进入** `process_logs/`，也不参与任何统计；
- 所有真实日志由 GitHub Actions 生成，服务端时间提供第三方锚点。
