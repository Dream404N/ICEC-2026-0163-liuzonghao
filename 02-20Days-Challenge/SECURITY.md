# 安全与隐私口径

## 数据来源

课表来自使用者本人提供的一张 Excel 截图，**人工逐格转录**为 `src/timetable.json`；
原图归档为 `src/timetable-source.png` 供校对。没有 `.xlsx` 原文件，因此**不做 OCR、
不假装读取 Excel**；看不清的字段标 `null` + `unclear`，由使用者对照原图核对。

程序只做两类对外访问：

- 向 Server酱 Turbo 的**官方公开 HTTPS 接口** `https://sctapi.ftqq.com/{SendKey}.send`
  发一个 POST，把课表提醒送到使用者本人扫码关注的「方糖」微信服务号；
- 不带 SendKey 的最小连通性探测（只判断域名可达性）。

## 微信合规边界（必须分清）

**明确不碰**：微信本地数据库、聊天记录、群消息、客户端逆向、登录微信客户端。
腾讯 2026-01 的 DMCA 下架（29 个仓库、连带 4,195 个 fork）针对的正是
「逆向客户端 → 破解本地加密数据库密钥 → 导出聊天记录」这类行为。

**本程序走的是相反方向的官方公开接口**：只把消息**送进**微信，不读取微信里任何数据，
不规避技术保护措施，不违反禁止逆向工程条款。这条区分写在这里，避免被误读。
本程序也不碰超星学习通、教务系统、校园网认证等需要账号或企业资质的接口。

旧版文档里「不碰微信」的 6 行声明针对的都是**读取**；2026-11-13 改选题后，
在保留这条底线的前提下开放「推送」，详见 `iterations/002-改选题说明.md`。

## 隐私

- 课表里的教师姓名、班级、课容量是公开职务/统计信息，保留在 `timetable.json` 与网页，
  **不写进 ICS 描述、不进日志、不进反馈**；
- 推送文案只带课程名、教室、教师（含待核对标记）、周次原文、教学形式；
- 不采集任何同学的姓名、学号、手机号、照片、位置、设备信息；
- 8 位反馈以 F01–F08 编号归档，截图如有昵称先打码。

## 日志脱敏

`src/chain.py` 统一处理，写入前机械抹除：Windows 用户路径、IPv4、**完整 URL**。
最后一条尤其关键——Server酱 的 POST URL 里含 SendKey，一旦进入异常栈会被 `_RE_URL`
替换成 `[url]`，因此日志里不会出现密钥。时间只到日期 + 分钟，不记毫秒、UTC 偏移、
主机名、绝对路径、请求正文。报错只保留脱敏后的 8 位 SHA-256 指纹用于归类，不写原始堆栈。

## 密钥

- **PreBell SendKey**：只放在 GitHub 仓库 `Settings → Secrets and variables → Actions`，
  变量名 `PREBELL_SENDKEY`；`prebell.yml` 通过 `env` 注入，`prebell.py` 只读
  `os.environ.get()`，缺失记 `skipped / no_key`，**绝不硬编码兜底**。
  不写进 `state/` / `process_logs/` / `public/` / commit message / 任何文档真值。
- 配置模板叫 `config.example.json`，**不叫 `config.json`**——`.gitignore` 全局排除该字面量，
  同步脚本的 `assert_no_secrets()` 又按 basename 二次拦截，叫错名字会导致整次同步中止。
  模板内容也不出现 `sk-` 形态的密钥串。
- 工作区外 `.workbuddy/.gh_token` 仅供同步脚本使用，永不入库；
  `.gitignore` 与 `assert_no_secrets()` 双重拦截，提交前做全仓密钥串扫描。
- GitHub Actions 使用仓库自带的 `GITHUB_TOKEN`，权限限定 `contents: write`。

## 诚信边界

- 缺勤轮次不补写，`verify.py` 按课表算出「该响没响的是哪一节」并点名；闹钟迟到只记录
  `late_by_min`，超 15 分钟宁可记 `missed_too_late` 不发，也不假装准时；
- 无课的日子就不产生记录，不为了凑「连续 N 天」让程序空转留痕；
- 推送失败如实记 HTTP 状态与 8 位错误指纹，**不写「推送成功」、不补记、不删**；
- 连通性先真实探测，境外机器连不上就降级到 `.ics` + 网页并在页面标注，不假装能推；
- 学期第 1 周周一 `2026-09-07` 是**估算**，四处同措辞标注「核对前请勿当作真实提醒」，
  绝不把估算包装成事实；
- `preview.html` 是版式样张，内含示例数据且已醒目标注，**不进入** `process_logs/`，也不参与统计；
- 所有真实日志由 GitHub Actions 生成，服务端时间提供第三方锚点；
- 改选题原因、旧口径作废清单如实记录，已提交的历史迭代记录（`001`）不回填、不修饰。
