## 一、一份反馈要收三样证据（少一样就只是「一句话评价」）

| 证据 | 具体怎么拿 | 为什么必须有 |
|---|---|---|
| ① 对话截图 | 微信里问、微信里答，直接截屏。**备注名和时间戳天然在图上**，比手写签名可信 | 证明是这个人、这个时间说的 |
| ② 界面截图 | 对方在你电脑上操作时按 `Win + PrtScn`，**任务栏时间要入镜** | 证明软件真的被运行过，不是看图说话 |
| ③ 一句原话 | 对方的抱怨照抄，**一字不改**（包括「太麻烦了，为什么做这个」这种） | 抱怨比夸奖更能证明是真人 |

可选加分：手机拍一张「手 + 屏幕」（不拍脸），证明现场有人。**不要拍正脸，不要拍学号。**

## 二、微信话术（复制即用，别写成问卷）

> 我在做个上课前自动提醒的小工具，装在我电脑上就行，试两分钟。
> 就三个问题：① 你觉得哪一步最别扭？② 到点的提醒你会不会真的按它去教室？
> ③ 你平时用什么提醒自己上课？

要点：
- **别一次发一长串问题**，对方会敷衍。两三个问题足够，剩下的靠你观察。
- 对方说完，回一句「好的我记一下，多谢」，然后立刻截屏，别等聊天被刷走。
- 如果对方说「挺好用」，追问一句「具体哪次帮到你了」——答不出具体的，就是客气话。

## 三、观察比提问更值钱（在你自己电脑上让对方操作）

| 观察点 | 记什么 |
|---|---|
| 入口 | 他第一下点的是桌面图标、开始菜单，还是问你「哪个是」？ |
| 装/开 | 从坐下到看见课表，多少秒？有没有卡在权限、杀毒、SmartScreen 提示？ |
| 会不会用 | 他自己找到「设置」了吗？改提前分钟数时问没问你？ |
| 到点反应 | 弹窗出现时他抬头了吗？有没有下意识看手机时间？ |
| 原话 | 一字不改记下来，包括骂人的话 |

## 四、每人必答（写进文件即可，不用都问）

1. 提醒有没有真的到？（微信 / 弹窗 / 手机日历 / 没收到 / 不确定）
2. 时间准不准，比上课早多久？
3. 内容看不看得懂？课程名、教室、节次有没有对不上的？
4. 哪一步最别扭？
5. 明天还会用吗？会不会推荐给室友？（**答「不会」照写，并写原因**）

## 五、命名与存放

```text
02-20Days-Challenge/feedback/
  user-01.md              一份一个文件，01–08
  evidence/U01-姓名或昵称-20261121.png   对话截图
  evidence/U01-运行截图-20261121.png     界面截图（带任务栏时间）
  summary.csv             全部填完后汇总，一行一人
```

`summary.csv` 表头（照这个顺序，一人一行）：

```csv
编号,用户标识,使用日期,用的哪套,最有用的地方,最想改的地方,是否继续用,证据文件
U01,室友-小李,2026-11-21,课序 0.1.4,到点右下角弹窗提醒去教室,"设置项找不到，要问才明白",会,evidence/U01-XXX-20261121.png
```

> 姓名字段建议写「关系 + 昵称」（如「室友-小李」「同班-阿May」），不必写全名，
> 但**必须是不同的人**。一人换代号不算两份。

## 六、如实边界（这几条比分数重要）

1. 不代填、不代改、不事后美化。要澄清就另附说明文件，**不动原文**。
2. 不抄别人仓库里的评价文字。同期有人在公开仓库贴了实名反馈，
   格式可以学，**内容一个字都不能搬**——搬了就是造假，而且能查出来。
3. 8 份必须是 8 个不同的人。凑不齐就如实写 5 份并说明原因，
   **不要为了凑数编 3 份**；评审更在意真假，而不是数字。
4. 不写手机号、身份证号、准考证号、真实姓名、住址。
5. 开发者不得替填写人决定措辞；对方说「就这样吧」，就照这样就。
