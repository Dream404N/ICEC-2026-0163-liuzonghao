# 真实用户反馈模板（复制 8 份：user-01.md … user-08.md）

> 诚信要求（admissions.html）：`如实提交原始数据，严禁造假或代做`；官网 L375 要求「8 位真实用户使用反馈」。
> **本模板只是格式，不是反馈本身**。8 份内容必须由真实使用过本工具的人填写，
> 不由开发者代写、不预填、不生成占位内容。文件命名用匿名代号，不出现真实姓名。

---

## 反馈记录

| 字段 | 内容 |
|---|---|
| 匿名代号 | U01（由填写人自定，勿用真实姓名/学号） |
| 使用日期 | YYYY-MM-DD |
| 身份（选填） | 同学 / 室友 / 家人（不写具体姓名与班级） |
| 使用场景 | 例如：周一第一大节前有课，收到出发与进教室两次提醒 |

### 收到提醒的情况

- 是否收到「课前 30 分钟 · 准备出发」：是 / 否 / 不确定
- 是否收到「课前 5 分钟 · 进入教室」：是 / 否 / 不确定
- 两次提醒是否都及时（有无明显延迟）：
- 消息内容是否看得懂、有没有把课表未核对的信息说清楚：

### 评价

- 这个功能对你/我使用有没有实际帮助（请写具体的一次经历）：
- 最需要改进的一点：
- 是否愿意继续使用：是 / 否
- 其他想说的：

---

## 填写说明

1. 请写真实经历，包括「没收到」「迟到了」「没看懂」等负面情况，负面反馈同样有效且更有价值。
2. 不要填写手机号、身份证号、准考证号、真实姓名、家庭住址。
3. 一人一份，8 份对应 8 位不同填写人。
4. 提交到 `02-20Days-Challenge/feedback/user-XX.md`（XX 为 01–08）。
