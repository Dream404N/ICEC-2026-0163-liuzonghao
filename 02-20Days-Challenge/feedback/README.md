## 一、先说清楚这批材料的边界

**这批是「对话截图」一类证据，不是完整的三件套。** 按 `TEMPLATE.md` 的要求，一份合格反馈要三样：

| 证据 | 本批覆盖情况 |
|---|---|
| ① 对话截图（备注名 + 时间戳） | ✅ 8 张，全部有微信时间戳 |
| ② 界面截图（任务栏时间入镜） | ❌ **0 张** —— 没有任何一张证明对方在自己电脑上运行过软件 |
| ③ 一句原话（一字不改） | ✅ 8 条全部逐字转录 |

**所以这 8 份只能证明「8 个人在指定时间说过这句话」，不能证明「这 8 个人用过这个软件」。**
评审若追问运行证明，本批材料无法回答。这一点写在前面，不藏在后面。

**另外三人（U01 / U04 / U08）的原始截图本来不可用或含他人隐私：**

- **U01**：对方回复里有一句与软件无关的不当玩笑，已按原样保留在记录中但**不建议作为评价引用**。
- **U04**：对方只回了一个表情包，**零文字**，无任何可转录内容。
- **U08**：原图含**另一位同学的真实姓名与学号**（`424-李梓杨`）及其开发的另一个软件名，
  已在上传版本中遮蔽姓名、学号与他人头像（遮蔽痕迹可见，未做图像修复）。

**三人均为本人真实微信联系人，未虚构、未用小号凑数。**
